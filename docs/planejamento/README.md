# Planejamento – LaCakes Cupcakes Gourmet

A LaCakes é uma confeitaria pequena, comandada pela confeiteira Laysa, que produz cupcakes gourmet todos os dias, em lotes limitados. Hoje as vendas são feitas no balcão e por mensagens no WhatsApp, o que gera pedidos anotados errado, perguntas repetidas sobre sabores e ingredientes e dificuldade para saber o que ainda tem no estoque do dia. A dona, Laysa, já teve uma experiência ruim com um aplicativo anterior, que não funcionava direito e foi retirado do ar. Por isso, o foco deste projeto é um sistema simples e confiável, com quatro pilares pedidos pelo cliente: vitrine virtual, pedido eletrônico, pagamento e entrega. O sistema será uma aplicação web responsiva (funciona como app no celular), com uma área administrativa para a equipe da loja.
